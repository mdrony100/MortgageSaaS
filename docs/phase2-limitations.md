# Phase 2 limitations and open release decisions

- Client requirements PDF and client Excel workbook were not supplied in the accessible attachments/repository. Fallback XLSX is implemented and marked; actual template matching remains pending.
- No approved lender policies, production thresholds, expense/ownership evidence, exception conventions or finalization gates supplied. Draft/examples never represent universal policy; affected income stays provisional/withheld.
- No live OpenAI/Ocrolus credentials, commercial/cost/data-processing approval, dedicated vendor Book or approved live sample documents were used. HTTP mocks prove contracts only; real extraction/Detect accuracy and entitlements are unverified. Unknown provider submission is intentionally blocked from automatic replay to avoid duplicate charges.
- Native normalization supports explicit labeled/pipe-column statement layout. Native text/page coordinates are preserved for other PDFs, but their structure stays unresolved unless approved vision extraction is configured. Mixed-account/mixed-period PDFs should be separated or remain incomplete; do not infer absent coverage.
- ClamAV implementation fails closed; actual signatures/infection detection must be accepted before real documents. Local explicitly fictional testing can use the clearly recorded bypass; it cannot run in production.
- Production-mode parsing of a fictional PDF was verified inside actual bubblewrap network/filesystem namespaces on this box. Docker daemon/container execution remains unavailable; each release host still needs sandbox/container acceptance. Local Python socket/resource restrictions are defense in depth only.
- S3-compatible private/encryption configuration and fake/local tests do not verify AWS, bucket policy, object locks, backups or infrastructure encryption. No resources deployed/provisioned.
- Provider raw payloads are not retained; seven-day encrypted replay cache expires, but long-term immutable evidence/customer retention and approved vendor deletion procedures still require legal/business signoff. Full identifiers are not retained as structured account fields; source originals necessarily remain sensitive.
- Browser visual/accessibility acceptance is unverified. Platform browser cgroup rejects loopback TCP to 8000 despite healthy shell HTTP; do not bypass its firewall or create a tunnel. Supported platform port allowance is needed for desktop review.
- Phase 3 appraisal/lease/photo/DSCR/LTV analysis, Plaid and production loan decisions remain out of scope and unchanged.

- Native supported-layout normalization is deliberately narrow; approved vision is required for other real layouts/scans. Synthetic contracts/native fixtures do not establish production extraction accuracy. Mixed-account or mixed-period originals must be separated; original bytes are not rewritten.
- PyMuPDF/MuPDF licensing and all customer/legal retention terms require release review. No commercial license/service was bought. No known pinned dependency advisories were found after patching Pillow; this is not a guarantee about every OS/native component.
- No real ClamAV executable/signature/infection run was available locally. The adapter and unavailable/rejected/failed contracts are tested; only explicit fictional acceptance uses bypass.

The documented Ocrolus upload contract is PDF-only. Native/vision ingestion still supports original JPEG/PNG, but no fabricated image-to-PDF forensic substitution is made; vendor acceptance of those originals is not verified and a rejection remains explicitly incomplete.
