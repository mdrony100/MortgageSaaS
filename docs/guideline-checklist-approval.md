`Guidelines::baseline()` contains short original summaries, not a copied Selling Guide. Sources were read live; citations are not model-memory inventions. Do not infer DSCR/Non-QM income formulas,75%haircuts, ADU caps, vacancy permission, seasoning, rounding or maximumLTV from these minimal summaries. Investor-specific application remains reviewer-verified.

## Version workflow
Baseline starts **draft**, named for Madison/designated client review. Registry stores source URL/section/retrieved/effective date, applicability/evidence/wording; version records add status/approver/time/notes/lineage. Owner/Admin with file access may create draft/retired versions. Production approval additionally requires explicit designated reviewer id in server configuration. No developer-created draft becomes production approved automatically.

Local/testing fictional files may simulate approval only with explicit demo flag; versions are `demo_only` and blocked from ordinary files. These tests are not client acceptance. Retirement appends a version pointing to the retired predecessor; fresh analyses reject it, while existing frozen runs/reports retain their original version unchanged.

Each run pins full checklist content/version. Updates never rewrite past analyses/reports. A human “Outside Fannie Mae Baseline” observation requires approved frozen rule id, reviewer-confirmed source evidence, explicit applicability confirmation and reason. Otherwise findings say “No explicit rule located” / “Verify Against Program Guidelines.” Baseline observations do not automatically disqualify Non-QM/DSCR or issue underwriting decisions.

## Required client review
Madison or designated reviewer must confirm applicability/content, approved identity and date, source update cadence, real form versions/exhibit paths, investor-specific review wording and any separate financial rounding/overlays. Initial official baseline is deliberately minimal and unapproved. Source availability failure must remain explicit; no invented source is approved as a substitute.
